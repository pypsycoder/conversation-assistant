# 12.11.2026 — выделение утверждений перед распределением по разделам

Запланированы три пары t01–t03, десять смыслов и десять обязательных размещений. Вариант должен извлечь отдельные утверждения с цитатами и типами. Код распределяет утверждения по трём разделам и сохраняет их формулировки и цитаты. Протокол и эталон зафиксированы в коммите 412509f до первого вызова. [Протокол](../examples/nightly-source-first-v1/PLAN.md)

## Остановка контроля

Свежий прямой SYSTEM_V2 на t01 вернул корректный JSON. GigaChat записал «Возраст не указан» в анамнезе жизни с единственной цитатой вопроса врача «Как менялось самочувствие?». Проверка опоры на реплику пациента отклонила ответ. Получена квитанция, ревизия GigaChat-3-Ultra:32.9.16.9 совпала с ожидаемой. API остановлен после первого вызова. Завершено 0 из 3 пар, у варианта 0 вызовов.

| Офлайн-разбор отклонённого ответа t01 | Результат |
|---|---:|
| TP / FP / FN по смыслу | 2 / 0 / 0 |
| Обязательные размещения | 1/2 |
| Жалобы | 0 обязательных, 1 запрещённое размещение |
| Анамнез заболевания | 1/2 обязательных размещений |
| Анамнез жизни | 0 клинических утверждений, 1 служебная строка без опоры |
| Неподтверждённые клинические утверждения, дубли, ошибки отрицания и времени | 0 |
| Ошибки источника | 1 |

В понедельник было легче, сегодня в целом хуже. Оба смысла сохранены. Сегодняшнее ухудшение попало в жалобы и отсутствует в анамнезе заболевания. Возраст действительно не обсуждался, статус not_discussed допустим в gaps. Служебная строка в анамнезе жизни учтена отдельно от клинических утверждений. Разбор выполнен Codex по синтетическому эталону. [Ответ, цитаты, разметка и квитанция](evidence/night-03-source-first/audit.json)

## Что показала офлайн-проверка

В шести сохранённых ответах r01–r03 предыдущей ночи было по одной служебной строке в анамнезе жизни. Все шесть прошли техническую проверку источников, поскольку содержали цитату пациента. В t01 модель сослалась только на вопрос врача. Служебные строки появлялись и в ответах с формально проверенными цитатами.

Имитированный запуск проверил маршрутизацию, сохранение текста и цитат, квитанцию и шаблон оценки. На вручную составленном примере новый режим сохранил обе строки в анамнезе заболевания. Добавление строки с одной цитатой врача снова вызвало ошибку опоры. Счётчик воспроизвёл ожидаемый результат на сохранённой имитации. Прошли 18 тестов. Эффект варианта на ответах GigaChat пока не измерен.

## Расход и следующий шаг

1 генерация, 1930 токенов (1464 входных и 466 выходных), 7,56 с генерации и 8,22 с запуска. Тариф неизвестен. Проверочный и финальный наборы остались зарезервированы.

Следующая гипотеза — одна и та же инструкция о хранении служебных сведений только в gaps для обоих вариантов позволит отдельно измерить эффект распределения. На новых синтетических примерах сначала проверить, сохраняются ли явно неизвестные сведения и сведения о жизни. Затем сопоставить новый контроль с вариантом. Ошибки источника и остановки учитывать отдельно от смысловых метрик.
