# Ночной результат PSYdraft — 08.11.2026

**Итог:** создан отдельный проект pypsycoder/conversation-assistant. Существующий
GigaChat-клиент работает при прямом HTTPS с проверкой TLS. Подготовлены воспроизводимый
runner, синтетический набор, проверка цитат, экспертная разметка и счётчик метрик.
Проверенное улучшение клинического качества пока не принято.

**Качество:** новая точка отсчёта — прямой v2, не инкрементальная основа S.
3 диагностических диалога, 12 составных клинических критериев, 18 выходных пунктов.
Полностью сохранено 12/12 (TP12/FN0), неподдержанных утверждений 1 (FP1),
precision 12/13 = 92.3%, recall 12/12 = 100%, F1 24/25 = 96.0%.
Обязательные размещения 15/15; из 16 размещений сопоставленных критериев 15 допустимы.
Дополнительное неподдержанное утверждение в этот знаменатель маршрутов не включено.
Необоснованных дублей, ошибок отрицаний/времени/источника в трёх разделах при этой
проверке — 0; это не оценка всех возможных ошибок или gaps. Пункты «не обсуждалось»
учтены как метаданные, не TP/FP. Рубрика и суждения Codex, не слепая врачебная оценка.
Набор короткий, клиническую пригодность эти числа не доказывают.

**Конкретные наблюдения:**
- Исправление начала бессонницы до 12 сентября сохранено вместо ранних «трёх недель».
- Два курса терапии переданы с дозами, датами, длительностью и разным эффектом.
- Сведения о матери сохранили «со слов сестры»; стаж «идёт двадцатый год» сохранил 19 полных лет.

**Оставшиеся проблемы:** отрицание панических приступов оказалось в жалобах;
из упоминания жены выведено «женат» без прямого подтверждения юридического статуса;
группы gaps не оценены полным независимым эталоном. Прямой v2 не интегрирован с Session
и врачебными правками. Более свежая S требует отдельного воспроизводимого адаптера.

**Неудачный эксперимент:** общий финальный контроль промпта. На тех же трёх входах
кандидат потерял размещение бессонницы в анамнезе болезни и сообщение жены об
раздражительности; третий ответ не прошёл provenance (пункт опирается только на вопрос
врача). На первом случае появился неверный unknown для явно отрицаемых приступов.
Кандидат отклонён; технически приняты 2/3, поэтому общую сравнительную F1 после
отбрасывания третьего случая не вычисляем. Никакой выборки только успешных ответов.

**Ресурсы:** baseline 8540 токенов / 29.922 с полного времени (API 23.083 с);
кандидат 8398 / 22.000 с. Всего 6 генераций, 16938 токенов.
Рубли неизвестны: тариф не настроен. Перед этим OAuth через прокси получил 10054,
генераций в неудачном соединении не было. Прямой режим не менял VPN/ОС.
25 локальных технических тестов прошли (18 из них входят в минимальную публикацию),
офлайн smoke прошёл. Исходные ответы, freeze, review и metrics сохранены локально
в data/nightly. В reports/evidence/2026-11-08 отобраны исключительно новые
синтетические ответы, суждения и итоги для воспроизведения подсчёта.
Секреты и прежние локальные data в Git не загружаются.

**Автономный запуск:** создана ACTIVE автоматизация Codex conversation-assistant,
ежедневно 23:00 по Москве. Старое задание отключено пользователем. Проверены запись
расписания и ручной короткий запуск, первое срабатывание по времени ещё не наблюдалось.
Нужны работающий компьютер, приложение и сеть. Есть OS-блокировка runner, пределы
на команду, общий ночной бюджет задан агенту (6 генераций/100000 токенов/30 минут).
Общий бюджет всех команд пока не является провайдерским финансовым ограничением.

**GitHub:** [отдельный репозиторий](https://github.com/pypsycoder/conversation-assistant).

штатным GitHub CLI. Слияние в main автоматически не выполняется.
