# Пересчёт Direct и S по эталону v2

11.11.2026 пользователь дал решения R1–R3. Они записаны в [бланке](../docs/clinical-review/2026-11-08/review-template.json).

| Решение | Правило в эталоне |
|---|---|
| R1 | Неизвестную причину тошноты требуется указать в анамнезе заболевания. В жалобах её можно повторить. |
| R2 | Текущее общее ухудшение самочувствия относится к анамнезу заболевания. Размещение в жалобах считается лишним. |
| R3 | Неизвестность психиатрических заболеваний отца требуется явно указать в анамнезе жизни. |

Для v01 отдельно оценены тошнота, время суток, длительность и неизвестная причина. Для v02 отдельно оценены три фазы самочувствия, неизвестность болезней отца и отсутствие общения с ним. Критерии операции в 2018 году и числа детей перенесены из v1. Упоминание года проверено по исходнику. Для фаз v02 год не указан. Эталон v2 содержит 11 критериев и 14 обязательных размещений на двух диалогах.

| Показатель | Direct | S |
|---|---:|---:|
| Полные критерии в трёх разделах | 10/11 | 11/11 |
| Обязательные размещения | 13/14 | 14/14 |
| Лишние размещения в жалобах | 1 | 3 |
| Неподтверждённые смыслы | 0 | 0 |
| TP / FP / FN | 10 / 0 / 1 | 11 / 0 / 0 |
| F1 по критериям v2 | 95,2% | 100% |

F1 показывает сохранение смыслов. Ошибки разделов учтены в строке про лишние размещения.

По R1 обе ветки выполнили требования к размещению. Direct указал неизвестную причину в анамнезе заболевания, S повторила её в жалобах.

По R2 обе ветки включили общее «сейчас хуже» в жалобы. S также перенесла туда февральское ухудшение и мартовское улучшение.

По R3 Direct указал неизвестность болезней отца в отдельном поле gaps. Требуемая запись в анамнезе жизни есть у S.

В пересчёте использованы четыре сохранённых ответа и 25 строк. Расход GigaChat составил 0 токенов. Пользователь определил правила R1–R3, сопоставление строк с критериями выполнил Codex. Цифры показывают оценку тех же ответов по новой рубрике.

Подробные суждения и метрики находятся в [каталоге evidence](evidence/rubric-v2). Скрипт проверяет восемь контрольных сумм исходного пакета и соответствие всех строк ранее проверенным ответам.

    python -B scripts/review_validation_rubric_v2.py --output data/nightly/rubric-v2-recheck
