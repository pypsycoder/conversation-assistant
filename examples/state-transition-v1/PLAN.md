# Состояние в период и момент ухудшения

Офлайн фиксируем шесть сопоставлений цитаты и текста, чтобы проверить существующее правило удаления жалоб. Проверяем, сохраняет ли строка анамнеза состояние, переход, время и повторяемость. Подмена и двусмысленность учитываются отдельно. Офлайн-часть диагностическая, код правки в этом сравнении не меняется.

Гипотеза для API. Одно явное указание о различии состояния и перехода поможет точнее отразить время, отрицание и повторяемость в прямом извлечении. Контроль — прежний SYSTEM_V2 с инструкцией о gaps. Вариант добавляет один абзац. Три новых диалога, десять критериев и десять обязательных размещений в каждом варианте. k01 проверяет разные дни и отрицание второго перехода. k02 проверяет период состояния при неизвестном начале. k03 проверяет явно названное повторное ухудшение и сохранение состояния к вечеру. Для k02 явная неизвестность нужна в анамнезе заболевания, её отражение только в gaps будет описано отдельно.

Одно обращение на диалог, сначала контроль. Ожидаемая ревизия GigaChat-3-Ultra:32.9.16.9. При сбое останавливаем API. После ответов Codex проверяет каждую строку и gaps по источнику и зафиксированному эталону. Для пользы нужно исправить по меньшей мере одну ошибку состояния или перехода без новых неподтверждённых утверждений, пропущенных обязательных смыслов и размещений, ошибок цитат, времени или отрицаний. Проверочный и финальный наборы зарезервированы. Оценка открытая, без врача.
