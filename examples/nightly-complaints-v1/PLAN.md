# Распределение общего ухудшения и конкретной жалобы

Гипотеза. Уточнение инструкции для прямого GigaChat уберёт общее изменение самочувствия из жалоб. Названные текущие симптомы и их динамика сохранятся.

Контроль использует SYSTEM_V2. Вариант добавляет один абзац перед заключительной сверкой. Для обеих инструкций подаются одинаковые новые диалоги r01–r03, по одному вызову на диалог. Сначала запускается контроль. Ожидаемая ревизия GigaChat-3-Ultra:32.9.16.9.

| Диалог | Что проверяется |
|---|---|
| r01 | Позавчерашнее улучшение и сегодняшнее общее ухудшение остаются в анамнезе заболевания. |
| r02 | Общее ухудшение с вечера остаётся в анамнезе заболевания. Звон в ушах попадает в жалобы. |
| r03 | Текущая дрожь рук попадает в жалобы. Усиление с утра по сравнению со вчерашним днём попадает в анамнез заболевания. |

Критерии заданы агентом до генераций. Смысл проверяется по каждой строке без участия GigaChat. Вариант проходит диагностику, если стало меньше запрещённых размещений в жалобах и во всех диалогах сохранены обязательные смыслы и размещения без новых неподтверждённых утверждений, ошибок отрицания, времени, источника или внутрисекционных повторов. Отдельно проверяются причины пробелов. Если контроль проходит без запрещённых размещений, эта выборка не подтверждает пользу уточнения. Трёх диалогов достаточно для диагностики и недостаточно для замены инструкции по умолчанию.

Используется только диагностический набор. Проверочный и финальный наборы остаются зарезервированы. Врачебная оценка этого набора не проводилась.
