# 19.11.2026 — восстановление общей динамики в анамнезе

Новая гипотеза: дословная фраза пациента с явным «мне» и временным обстоятельством
безопаснее генеративного пересказа для восстановления пропущенного «снова/опять»
и различения плохого состояния и нового ухудшения. Пользователь прямо поручил
исправление, офлайн-проверку и свежий GigaChat.

Отдельный экспериментальный модуль history_course_repair, без изменения Session.
Конечная грамматика: общее состояние и дословные переходы из прежней правки.
Полное предложение, заключительная фраза после явного облегчения либо общая фраза
перед ограниченной текущей жалобой. Условия/неуверенность не отрезаются.
Заменять можно только отдельную общую строку с одной точной цитатой того же
источника; отсутствующую фразу добавить дословно. Смешанные анамнезы, лишние
значения, широкие/множественные цитаты и повторные уточнения не переписывать.
Никакого назначения общего времени началу симптома, диагнозов и назначений.

Контроль — действующая ограниченная правка жалоб. Кандидат восстанавливает анамнез
по источнику и затем повторяет ту же ограниченную правку жалоб. Нужны неизменные
симптомы, их время, сила, сторона, условия, отрицания, life_history и gaps.
Дубли, новые смыслы и потери запрещены. Сначала одиннадцать новых офлайн-сценариев
с ручными ожидаемыми результатами и негативными случаями, затем шесть новых y01–y06
(17 критериев) с одним свежим прямым ответом на диалог. До/после — один и тот же
ответ. Оба этапа, код и gold зафиксировать до API. GigaChat не оценивает себя.
Оценка Codex открытая, без врача. Final/validation не использовать.

Контрольный промпт прежний examples/nightly-gaps-routing-v1/control-prompt.txt.
Ревизия ожидается GigaChat-3-Ultra:32.9.16.9, --direct, TLS включён.
Общий лимит цикла с 10:35:51 UTC — 30 минут, 6 генераций и 100000 токенов.
Каждой команде API передать оставшийся бюджет. Новый output. При сбое или смене
ревизии остановить API. Прежняя candidate h02 остаётся неизвестной и не повторяется.
Для спорных значений — отказ/awaiting_physician_review, без автоматического продвижения.
