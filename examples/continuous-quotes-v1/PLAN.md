# Непрерывные цитаты для трёх разделов

Гипотеза после остановки на k02. Одно уточнение к действующей инструкции увеличит долю технически допустимых цитат. Дословные разнесённые фрагменты допускаются в отдельных элементах evidence одной строки, в том числе из одной реплики. Отдельные строки и одна более длинная непрерывная цитата также допустимы. Схема и проверка источников прежние.

Три новых синтетических диалога j01–j03, девять критериев и девять обязательных размещений на вариант. j01 проверяет два текущих симптома и отрицание между ними. j02 проверяет приём, неизвестную дозировку и состояние через час, включая отсутствие добавленной причинности. j03 даёт непрерывный фрагмент с двумя временными состояниями и последующим отрицанием возврата боли. Для j02 неизвестность дозировки нужна в анамнезе заболевания, gaps оцениваются отдельно.

До шести генераций. Сначала три ответа по новой инструкции, чтобы получить наблюдения о ней даже при технической остановке контроля. Затем свежий контроль SYSTEM_V2 с прежней инструкцией о gaps на тех же входах. По одной генерации на диалог в каждом варианте. Ожидаемая ревизия GigaChat-3-Ultra:32.9.16.9. При сбое или смене ревизии API останавливается. Анализ только фактически завершённых пар, отклонённые ответы рассматриваются отдельно.

Отдельно считаем непрерывность цитат и смысловую опору строк. Улучшение требует меньше строк с ошибками дословности при сохранении смыслов, времени, отрицания, обязательных размещений и без новых неподтверждённых утверждений и ошибок gaps. При полном техническом прохождении обеих веток сравниваем содержание и фиксируем, что разницу в допустимости цитат выборка не показала. Оценка Codex открытая, без врача.
