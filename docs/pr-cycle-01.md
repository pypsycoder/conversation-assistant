Первый исследовательский цикл вне расписания по поручению пользователя.
Зависит от PR #1; целевая ветка этого PR — research/nightly-baseline-2026-11-08,
чтобы отдельно показать только изменения цикла.

В print_v2 упоминание родственника и глагол из следующего предложения ошибочно
подавляли обязательную пометку источника. Например, «Раздражается на мужа.
Пациентка говорит…» считалось явной атрибуцией мужу. Новый print_v3 ограничивает
прежнюю проверку границами сообщений. Замороженный print_v2 и реестры не меняются.
Выборочно импортированы готовые зависимости принятой S и их технические тесты.

На отдельной синтетической рубрике печати: диагностические примеры 0→6/6,
проверочные 10→10/10. На 9 сохранённых синтетических реестрах S (3 диалога × 3
повтора), 1002 размещения: 0 изменённых строк, SHA входов и остальные поля сохранены.
50 технических тестов прошли, в том числе из чистого git archive; опубликованная
рубрика также воспроизводится из архива. API-вызовов и модельных токенов — 0.

Это проверка печати источника, не extraction F1 и не независимая врачебная
валидация. На старых 1002 строках улучшение не обнаружено. Эвристика основ слов
и неоднозначность субъекта внутри предложения остаются. Старые runner не
переключены, main не сливается автоматически. Данные реестров остаются локальными.
