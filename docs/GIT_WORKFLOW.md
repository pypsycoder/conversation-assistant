# Git ведёт агент

Поручение пользователя от 08.11.2026: ветки, коммиты, push и PR агент выполняет
самостоятельно через команды и скрипты. Репозиторий — pypsycoder/conversation-assistant;
psydraft остаётся отдельным проектом. Автоматического слияния в main нет.

Используются штатный git и официальный GitHub CLI. Локально gh 2.103.3 размещён
в .tools/gh-2.103.3/app/bin/gh.exe: загружен из релиза cli/cli, SHA256 zip проверен
по метаданным GitHub. .tools исключён из Git. На другом компьютере можно поставить
GitHub CLI обычным способом и использовать gh из PATH.

Единственный ручной шаг при первом подключении — gh auth login. Подтверждение
входа выполняет пользователь на странице GitHub, токены в чат не передаются.
Работающую авторизацию git менять не требуется. Сохранённые учётные данные
не извлекаются для самодельных API-запросов.

Порядок работы агента:

1. Проверить текущую ветку, origin и diff; не трогать чужие незавершённые изменения.
2. Добавить в индекс только конкретные файлы задачи. Прежние локальные материалы,
   которые пока вне Git, не удалять и не импортировать целиком.
3. Проверить staged diff и выполнить scripts/check_research_publish.py.
4. Запустить проверки, соответствующие изменению, и сделать коммит.
5. Выполнить scripts/git-pr.ps1: он проверяет origin, отдельную ветку, чистоту
   отслеживаемых файлов и аккаунт pypsycoder, делает обычный push и создаёт draft PR.
   Если открытый PR уже существует, возвращает его ссылку без дубликата.

```powershell
# Проверить предпосылки без публикации:
& .\scripts\git-pr.ps1 -CheckOnly

# Опубликовать текущую ветку и получить draft PR:
& .\scripts\git-pr.ps1
```

Для следующей задачи передать свои -Title и -BodyFile; описание готовить файлом
с настоящими переводами строк. Скрипт не делает git add, commit, merge или force push.
Ссылку на созданный PR агент прикрепляет к чату. Новые поколения GigaChat ради
обычных Git-операций не запускаются.
