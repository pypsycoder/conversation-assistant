# Следующие эксперименты

1. Завершить связь GigaChat: прокси сбрасывает OAuth. Проверить прямое соединение
   при обычном TLS. Не менять VPN, сертификаты ОС и секреты. При неизвестной квитанции
   генерации не повторять её автоматически. Проверить баланс/тариф отдельно, если доступен.
2. Получить прямой v2 reference d01–d03 и полностью разметить каждый пункт с источником.
   Зафиксировать SHA ответов и gold; рубрика не врачебная. Метрики не смешивать со старыми.
3. Добавить адаптер принятой S к тем же беседам; включить все её зависимости в
   отдельный проверяемый импорт. Сравнить direct/S на одинаковых критериях, не менять default.
4. По диагностике проверить ОДНУ общую гипотезу сохранения поздних исправлений.
   Заморозить критерии до API, свежий контроль, затем validation, 3 повтора при пользе.
5. Укрупнённые gold-критерии разделить в новой версии на атомарные атрибуты;
   пересчитать обе ветки, не переписывая v1. Врач проверяет эталоны независимо.
6. Настоящий слепой финальный набор поручить врачу. f01 сейчас резервный, не слепой.
7. Адаптер в Session и устойчивые ID для правок врача — после подтверждения качества.

Не повторять редактор/сложный граф/предложенные замены P без новых доказательств.
Сначала содержание, отрицания, время и источники; валидный JSON недостаточен.
