# Инструкции проекта

## Цель

Создать локальный русскоязычный модуль распознавания диалога врач–пациент во время психиатрического приёма. Результат: проверяемые жалобы и симптомы, черновик протокола в структуре PsyDraft.

## Работа

- Основные требования: `docs/requirements.md`; порядок работ: `docs/roadmap.md`.
- Опора на PsyDraft: `docs/psydraft-mapping.md`. Проверять реальные поля исходников, а не только README или пустую FORM_SCHEMA.
- Код и документы этого проекта изменять в текущей папке. Исходный PsyDraft читать как референс; его изменение требует отдельной задачи пользователя.
- Отмечать предположения и отличать планируемую функцию от реализованной.
- Сначала контракт данных и синтетические сценарии, затем интеграция распознавания и интерфейса.
- Сохранять врачебные правки при обновлении моделей и расшифровки.
- Каждый извлечённый факт связывать с источником, временем, ролью говорящего и версией текста.
- Отсутствие упоминания не означает отсутствие симптома. Не переносить нормальные значения по умолчанию из PsyDraft в автоматический черновик.
- Разделять сообщение пациента, сообщение родственника и наблюдение врача. Наблюдения о внешности не выводить из аудио пациента.
- Не добавлять автоматическую постановку диагноза, назначения или оценку уровня риска без согласования новой задачи.
- Использовать синтетические примеры. Не читать и не копировать реальные истории пациентов для разработки без отдельного основания.
- В новых синтетических интервью соблюдать правило пользователя «один вопрос врача → один ответ пациента»: один самостоятельный предмет запроса в реплике, затем ответ, затем следующий вопрос. Не объединять разные темы или независимо отвечаемые вопросы через «и». Ответ пациента может содержать дополнительные сведения; их полноту сохранять. Прежние frozen-наборы не переписывать — исправленный сценарий получает новую версию.
- Не коммитить аудио, расшифровки, идентификаторы пациентов, локальные модели или секреты.
- Новые зависимости и версии выбирать после проверки документации и измерения на целевом компьютере.

## Пользовательская память о сети

На Windows встроенный браузер Codex не загружал сайты через v2rayN в TUN-режиме (`ERR_CONNECTION_RESET`, `ERR_PROXY_CONNECTION_FAILED`). После перехода на Happ VPN с sing-box заработал. При повторении сначала проверять совместимость и маршрутизацию v2rayN/TUN; не сбрасывать профиль и сертификаты без оснований. Raspberry Pi 5 доступен через Raspberry Pi Connect, его веб-интерфейс открывается во встроенном браузере.
